# 스타쉽 질주

우주에 떠 있는 길을 따라 우주선을 몰고 끝까지 날아가는 3D 웹 레이싱 게임입니다. 브라우저만 있으면 설치 없이 플레이할 수 있습니다.

**▶ [플레이하기](https://jhleebre.github.io/starship/)**

## 게임 규칙

- 틈은 점프로 뛰어넘고, 벽은 옆으로 피해 가세요. 벽은 반투명해서 너머의 길이 보입니다.
- 빠른 속도로 벽에 부딪히면 폭발합니다. 속도가 느리면 멈추기만 합니다.
- 연료는 달린 거리만큼 줄어듭니다. 초록색 연료 칸을 밟으면 가득 찹니다. 1~2단계는 연료가 넉넉해서 줄어들기만 하고 바닥나지는 않으며, 3단계부터는 연료 칸을 챙기지 않으면 끝까지 갈 수 없습니다.
- 체크무늬 결승선에 도착하면 단계를 끝내고 다음 단계가 열립니다. 단계별 최고 기록이 저장됩니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| `←` `→` 또는 `A` `D` | 좌우로 움직이기 |
| `↑` 또는 `W` | 가속 |
| `↓` 또는 `S` | 감속 (멈춘 뒤 계속 누르면 후진) |
| `스페이스` | 점프 |
| `R` | 다시 시작 |
| `Esc` 또는 `P` | 일시정지 · 메뉴 |
| `M` | 모든 소리 켜기/끄기 |
| `N` | 배경음악 켜기/끄기 |

터치 기기에서는 화면 아래 버튼으로 조작합니다.

## 바닥 종류

| 색 | 이름 | 효과 |
| --- | --- | --- |
| 파랑 | 가속 | 잠시 최고 속도보다 빨라집니다 |
| 갈색 | 감속 | 위에 있는 동안 속도가 크게 줄어듭니다 |
| 초록 | 연료 | 연료가 가득 찹니다 |
| 빨강 | 불바닥 | 닿으면 폭발합니다 |
| 노랑 | 도약대 | 벽도 넘을 만큼 높이 띄워 줍니다 |

## 단계

| 단계 | 이름 | 새로운 요소 |
| --- | --- | --- |
| 1 | 첫 비행 | 틈, 벽 |
| 2 | 계단 구름 | 올라탈 수 있는 낮은 블록 |
| 3 | 가속 터널 | 가속 · 감속 바닥, 연료 관리 시작 |
| 4 | 불꽃 지대 | 불바닥 |
| 5 | 도약대 기지 | 도약대 |
| 6 | 무거운 행성 | 강한 중력 |
| 7 | 달빛 저중력 | 약한 중력 (벽도 뛰어넘을 수 있음) |
| 8 | 유성 고속도로 | 더 빠른 속도, 조금 강한 중력 |
| 9 | 은하 끝 | 가장 길고 연료가 가장 빠듯함 |

코스는 단계마다 정해진 시드로 만들어지므로 매번 같은 길이 나옵니다.

## 로컬 실행

빌드 과정은 없지만, 코드가 ES 모듈로 나뉘어 있어서 `index.html`을 파일로 바로 열면 동작하지 않습니다. 프로젝트 폴더에서 로컬 서버를 띄운 뒤 브라우저로 접속하세요.

```bash
python3 -m http.server 8000
```

그다음 `http://localhost:8000` 을 엽니다. GitHub Pages 같은 정적 호스팅에는 그대로 올리면 됩니다. [three.js](https://threejs.org/)(r128)와 Google Fonts를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 폴더 구조

```
index.html              화면 마크업과 모듈 진입점
css/style.css           HUD · 메뉴 · 터치 버튼 스타일
src/
  main.js               초기화와 프레임 루프
  game.js               게임 흐름 (메뉴/플레이/일시정지/폭발/도착), 입력 → 동작
  config.js             물리 상수, 타일 규칙
  data/
    segments.js         코스 조각 (타일 문자열)
    levels.js           단계 목록 (중력, 속도, 연료, 색)
  world/                ← three.js·DOM을 쓰지 않는 순수 로직
    generator.js        시드 기반 코스 생성
    track.js            타일 조회, 충돌 판정
    physics.js          우주선 시뮬레이션 (이벤트 콜백으로 결과 전달)
  render/
    renderer.js         렌더러, 장면, 카메라, 조명, 그림자
    textures.js         캔버스로 그리는 텍스처와 타일 아이콘
    sky.js              그라데이션 하늘, 별, 성운, 행성
    ship.js             우주선 모델(createShipModel)과 화면 표시
    trackMesh.js        코스 메시, 반투명 벽, 결승 게이트
    effects.js          파티클, 폭발 파편, 효과 프리셋
    cameraRig.js        추적 카메라
  audio/sound.js        WebAudio로 합성하는 효과음
  audio/music.js        WebAudio로 합성·예약 재생하는 배경음악 (단계가 오를수록 악기가 늘고 빨라짐)
  ui/hud.js             HUD, 배너, 메뉴, 결과 카드
  ui/input.js           키보드·터치 → 동작 이름
  util/storage.js       기록 저장 (localStorage)
  dev/
    solver.js           단계를 끝까지 가는 입력을 찾는 탐색 봇
    autoplay.js         봇이 찾은 입력으로 실제 게임을 자동 플레이 (QA용)
tools/
  level-check.js        모든 단계를 끝까지 깰 수 있는지 확인 (solver.js 사용)
  check-levels.html     브라우저에서 확인 (로컬 서버로 열기)
  check-levels.mjs      Node에서 확인 (`npm run check-levels`)
```

이미지·소리 파일은 없습니다. 텍스처는 `render/textures.js`에서 캔버스로 그리고, 효과음과 배경음악은 `audio/`에서 합성합니다.

## 코스 수정하기

1. `src/data/segments.js`에 조각을 추가하거나 고칩니다. 타일 문자는 `src/config.js`에 설명되어 있습니다.
2. 단계별 설정은 `src/data/levels.js`에서 바꿉니다.
3. 바꾼 뒤에는 모든 단계를 끝까지 깰 수 있는지, 그리고 3단계부터는 연료 없이는 깰 수 없는지 확인합니다. 로컬 서버에서 `http://localhost:8000/tools/check-levels.html` 을 열거나, Node가 있다면 아래 명령을 실행합니다.

```bash
npm run check-levels
```

## 자동 플레이 (QA)

주소 뒤에 `?autoplay`를 붙이면 봇이 1단계부터 마지막 단계까지 실제 게임을 플레이합니다. 단계마다 먼저 깰 수 있는 입력을 계산한 뒤 화면에서 그대로 재생하므로, 코스·물리·이펙트·결과 화면을 눈으로 확인할 수 있습니다.

- `http://localhost:8000/?autoplay` : 1단계부터
- `http://localhost:8000/?autoplay&from=5` : 5단계부터
- 자동 플레이 중에는 키 입력을 받지 않으며, `Esc`로 멈추고 메뉴로 돌아갑니다. 자동 플레이 기록은 최고 기록에 저장되지 않습니다.
